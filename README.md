
# Python Bootcamp — Team Project

CSC10014 — Git & GitHub for Team Projects

## Repository structure

- `members/`: Individual homework, organized by member and week.
- `shared/`: Shared team code for T-W2 and T-W3.
- `tests/`: Instructor-provided test files.
- `PROGRESS.md`: Weekly progress and pull request links.

## Setup

Follow the Python environment setup instructions provided
by the course starter repository.

## Run tests

```bash
pytest -q
```

## Team workflow

1. Pull the latest changes from `main`.
2. Create your own branch.
3. Work only in your assigned member folder for individual exercises.
4. Commit each exercise separately.
5. Push your branch and open a pull request.
6. Request a teammate to review your pull request.
